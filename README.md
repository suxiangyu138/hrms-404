# 人事管理系统数据库课程设计 · HRMS-404

> **404 Not Found 小组** · 数据库课程设计项目
> 项目代号：**HRMS-404**（Human Resource Management System × 404 Not Found）

一个基于 **Java + Spring Boot + MySQL** 的人事管理系统课程设计项目。系统覆盖部门、员工、考勤、薪资等核心人事业务，并将**数据库理论**（范式设计、视图、存储过程、触发器）与 **AI 大模型应用**（DeepSeek V4 Flash 自然语言转 SQL）结合，作为本项目区别于一般增删改查系统的亮点。

---

## 📦 技术选型

| 类别 | 选型 | 用途 |
|------|------|------|
| 开发语言 | Java | 全项目统一 Java 开发 |
| 构建工具 | Maven | 依赖管理与打包 |
| 后端框架 | Spring Boot + Spring MVC | IoC/AOP、RESTful 接口、声明式事务 |
| ORM 持久层 | MyBatis-Plus | 简化 CRUD、自定义 SQL、调用存储过程 |
| 前端 | Thymeleaf + Bootstrap | 服务端渲染响应式页面 |
| 数据库 | MySQL 8.0 | 视图 / 存储过程 / 触发器 |
| AI 大模型 | DeepSeek V4 Flash API | Text to SQL 自然语言查询（OpenAI 兼容协议） |

## 🧩 功能模块

| 模块 | 说明 |
|------|------|
| 员工管理 | 多条件组合查询、逻辑删除（离职）、职位随部门联动 |
| 部门管理 | 上下级树形结构、递归查询子部门人数（存储过程） |
| 考勤管理 | 每日一卡、重复打卡校验、日期范围查询 |
| 薪资管理 | 按月批量生成薪资（存储过程）、实发自动计算（触发器） |
| 用户权限 | 管理员 / HR / 经理 / 员工 四角色 RBAC 权限控制 |
| **Text to SQL** | 输入自然语言 → DeepSeek V4 Flash 生成 SQL → 安全校验 → 执行并渲染结果表格 |

## 🗄️ 数据库设计亮点

- 关系模式规范化达到 **BCNF**（Boyce-Codd 范式），单字段主键、消除传递依赖
- 3 个视图：员工完整信息、考勤汇总、薪资历史
- 3 个存储过程：部门人数统计、月度薪资生成、组织树递归查询
- 4 个触发器：离职自动禁用账号、入职自动建账号、实发工资自动计算、编制预算校验

## 🤖 Text to SQL（AI 亮点）

- 调用 **DeepSeek V4 Flash API**（`/chat/completions`，OpenAI 兼容格式）
- 系统提示词内嵌全部表结构 DDL，保证 SQL 使用正确表名
- 安全约束：仅 SELECT、禁止系统库、强制 LIMIT、超时与限流控制

## 🏷️ 小组特征元素（404 Not Found）

组名取自 HTTP 状态码 404，系统各处以"404"为品牌线索：自定义 404 错误页、页脚署名、空数据占位提示"404：暂无数据"、顶栏徽标、控制台彩蛋等（完整清单见 [`开发文档.md` 第 4.4 节](开发文档.md)）。**既是一张小组名片，也与错误页/空数据场景天然契合。**
